# ASXRunTerminal CLI

## Objetivo do Projeto

Construir o **ASXRunTerminal CLI** como um terminal de linha de comando equiparado ao **Copilot CLI**, com foco em produtividade para desenvolvedores e execução local de IA.

O projeto deve permitir:

- executar e orquestrar modelos do **Ollama** via terminal;
- oferecer uma experiência simples, rápida e confiável para comandos com IA;
- integrar fluxos de desenvolvimento (geração de código, revisão, automação e suporte técnico);
- manter controle local dos modelos e dos dados, priorizando desempenho e privacidade.

## Desenvolvimento
